**In command line:** ``-t/--fileType edgelist``

Edge lists are a common representation of graphs, where each row encodes an edge as a pair of nodes (unweighted) or a triple (weighted).

**Unweighted edge list**

.. csv-table:: Header
   :width: 40%
   :header: V1, V2
   :widths: 20, 20

   A, B
   A, C
   B, C

**Weighted edge list**

.. csv-table:: Header
   :width: 50%
   :header: V1, V2, W
   :widths: 20, 20, 10

   A, B, 0.7
   A, C, 0.3
   B, C, 0.9
