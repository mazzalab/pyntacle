Graph Utilities
===============

This section groups a set of *practical* commands meant to manipulate, compare, convert, and quickly explore graphs.
They are especially useful when working with multiple experimental conditions (e.g., WT vs mutant networks) and when you need fast transformations and sanity checks before running centrality/topology analyses.
